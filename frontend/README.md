# Frontend (React Native + Expo)

L'application frontend est conçue avec **Expo** et **React Native**.

L'approche "File-Based" s'applique grâce à **Expo Router** (dossier `app/`).

## Lancer l'application

```bash
npm install
npm start
```

*(Note : Ce dossier est conçu pour être lancé nativement ou via Podman en fonction des besoins, bien qu'il soit courant de l'exécuter localement pour utiliser les simulateurs iOS/Android)*.
